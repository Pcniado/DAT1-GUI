# Building Overstrike

## Short Version

1. Clone the repo.
2. Open `Overstrike.sln` in Visual Studio.
3. Build and run the project (press **F5**).

> Visual Studio should automatically restore required packages. Make sure you have the .NET toolchain installed.

---
